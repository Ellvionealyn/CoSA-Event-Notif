# CoSA E-Attendance Mobile Application

## Project Description
CoSA E-Attendance is a mobile application developed using **MIT App Inventor** to help the Computer Science Association (CoSA) at UiTM Sabah manage attendance during events and activities.

The application allows members to record their attendance by scanning QR codes, replacing the traditional paper-based attendance system.

## Project Information
- **Project Title:** CoSA E-Attendance Mobile Application
- **Course:** CSC264 – Introduction to Web and Mobile Application
- **Developer:** Ellvionealyn Francis
- **Date:** June 2024
- **Development Tool:** MIT App Inventor
- **Platform:** Android

## Features

**CoSA Members**
- Log in using registered credentials.
- View upcoming events and event details.
- Scan QR codes to record attendance.
- View personal profile information.

**Admin (Student Council)**
- Add, edit, and delete events.
- View attendance records.
- Display QR codes for members to scan.

## How to Run the Application

**Important:** This application was developed using MIT App Inventor and is distributed as an Android APK file. Users must download and install the APK to run the application.

1. Download the `.apk` file from this GitHub repository.
2. Transfer the APK file to an Android device if downloaded using a computer.
3. Open the APK file on the Android device.
4. Allow installation from the selected source if prompted by Android.
5. Complete the installation.
6. Open **CoSA E-Attendance** and log in to use the application.

**Note:** The APK is intended for Android devices and cannot be installed directly on iOS devices. Only install the APK if you trust the source.

## User Instructions
1. Launch the application.
2. Log in using your registered account.
3. Select an available event.
4. Scan the QR code displayed during the event to record your attendance.
5. Admin users can manage events and view attendance records through the admin interface.

## Project Background
This application was developed as an individual assignment for CSC264 at Universiti Teknologi MARA (UiTM) Sabah. Its purpose is to improve attendance management by reducing paperwork, saving time, and making attendance records easier to manage.
